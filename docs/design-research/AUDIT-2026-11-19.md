# AUDIT — PRATA FAKTA (Fase 1 Redesign World-Class UI/Motion)

**Tanggal:** 19 November 2026 · **Branch:** `redesign/world-class-ui-motion` (dari `main` a0a4c1c, merge PR #24)
**Repo:** `~/workspace/prata-fakta` · **Live:** https://prata-fakta.vercel.app/ (HTTP 200, diverifikasi)
**Ruang lingkup:** audit saja — TIDAK ada kode aplikasi yang diubah di fase ini.

## 0. Ringkasan eksekutif

PRATA FAKTA adalah aplikasi yang **fungsional dan rapi secara Swiss** (sistem token konsisten,
tipografi Inter + Source Serif 4, aksen crimson), tetapi **terasa statis dan datar pada
pandangan pertama**: hero hanya teks, tidak ada transisi halaman, tidak ada reveal,
library animasi terinstal tapi 0 berkas memakainya, dan "liquid glass" saat ini adalah
latar **solid** (nama saja). Pelajaran dari PRATA ENGLISH ("masi biasa aja" untuk paket
motion yang halus) berlaku penuh di sini: redesign harus mengubah masthead, hero, kartu,
dan BottomNav secara visual — bukan hanya menambah micro-motion.

**5 temuan terpenting:**
1. **Motion = 0.** `motion` ^14.14.0 terinstal sejak V3 tapi TIDAK DIIMPOR di berkas mana
   pun. Satu-satunya animasi yang terlihat adalah indikator BottomNav (spring 560ms).
   Tidak ada transisi rute, staggered reveal, atau reveal gambar.
2. **"Kaca" palsu.** Token `--glass-bg`/`--glass-border` bernilai solid
   (`#ffffff` / `#e3e0d8` terang; `#171b1e` gelap) — komentar kode sendiri menulis
   "Swiss: solid". BottomNav memang sudah punya SATU indikator kaca bergerak
   (sudah benar), tapi tidak ada blur/transparansi nyata di mana pun.
3. **Graf Pengetahuan rusak secara visual.** Label simpul terpotong di tepi kiri
   ("olisi Tangkap 5 Orang Bu…", "OTO: Umat Hindu India Be…"), garis bersilangan
   acak, dan pil filter menampilkan kategori kosong (Klaim 0, Sumber 0,
   Peristiwa 0, Cerita 0, Negara 0) dengan gaya yang sama seperti kategori berisi.
4. **Jargon internal bocor ke pembaca.** Byline artikel menulis
   "Oleh Redaksi PRATA FAKTA (draf pipeline)"; kotak FACT SCORE mengulang
   "Belum dinilai — Belum dinilai — belum ada klaim terverifikasi…".
5. **Admin tidak bisa diaudit visual tanpa login.** `/admin` sebagai tamu
   mengalihkan ke `/masuk` (perilaku BENAR — guard server). Seluruh shell admin
   (42 halaman) berstatus BLOCKED untuk audit visual fase ini; audit admin hanya
   dari kode (layout + NavAdmin).

## 2. Sistem desain saat ini

- **Token:** `src/app/globals.css` **2.583 baris**, satu berkas monolit; 46 properti kustom
  (`--bg`, `--surface`, `--surface-2`, `--elevated`, `--ink`, `--ink-2`, `--muted`,
  `--border`, `--accent`, `--danger`, `--warn`, `--shadow`, `--shadow-glass`,
  `--glass-bg`, `--glass-border`, `--radius` 12/16/20, `--maxw` 1200px).
  Warna terang: bg `#f9f8f5`, aksen crimson `#b91c1c`; gelap: bg `#0e1113`,
  aksen `#f87171`. Kontras `--muted` diklaim ≥4.5:1.
- **Tipografi:** `--font-sans: Inter`, `--font-serif: "Source Serif 4"` (serif dipakai
  luas untuk headline). Tidak ada font display khusus.
- **Ikon:** `lucide-react` ^1.73.0 terinstal tapi hanya diimpor **9 berkas**.
  BottomNav memakai **SVG inline gambar tangan** (komentar kode mengklaim
  "lucide-react TIDAK terinstal" — komentar usang). Tidak ada sistem ikon terpadu.
- **Komponen:** 90 berkas `src/components/*.tsx` (+ subfolder admin, akademi, artikel,
  cerita, data, data-live, graf, izin, lanjutan, laporan, negara, peta, podcast, pwa,
  riset, saya). Kunci: `BottomNav`, `CommandPalette` (570 baris), `Header`,
  `HeaderNav`, `Kartu`, `GarisWaktu`, `Footer`, `SearchBar`, `ThemeToggle`,
  `NotifikasiBadge`, `SaranPencarian`, `TombolCari`, `NewsletterForm`,
  `PelacakKunjungan` (wilayah terlarang — jangan disentuh).
- **Tema:** skrip inline `TemaInit()` di `layout.tsx` + `HASH_SKRIP_TEMA` di
  `src/lib/csp.ts` (JANGAN ubah satu karakter tanpa hitung ulang hash);
  `localStorage pf-tema`; sistem via `prefers-color-scheme`. `prefers-reduced-motion`
  sudah ditangani di 4 blok CSS.
- **Animasi:** `motion` terinstal, **0 impor**. Radix Dialog + Dropdown Menu terinstal
  (`@radix-ui/react-dialog`, `react-dropdown-menu`). TIDAK ada GSAP, Rive, Spline,
  Three.js. `<Suspense>` dipakai di 16 berkas (pola `cacheComponents` dipatuhi).
- **Pencarian:** `CommandPalette` sudah ada — Ctrl+K/Cmd+K, riwayat lokal, saran,
  navigasi keyboard, pemicu di header. Halaman `/cari` terpisah juga ada.

## 3. BottomNav (arsitektur info — WAJIB dipertahankan)

6 item, satu indikator kaca bergerak (translate3d per indeks, spring 560ms
cubic-bezier overshoot, opacity 0 di rute tak dikenal):

| # | Label | Tujuan | Aktif di |
|---|---|---|---|
| 1 | Beranda | `/` | `/` |
| 2 | Kategori | `/kategori` | `/kategori*` |
| 3 | Arsip | `/arsip` | `/arsip*` |
| 4 | Daily Brief | `/brief` | `/brief*` |
| 5 | Saya | `/saya` | `/saya*`, `/masuk`, `/daftar` |
| 6 | Lainnya | `/jelajahi` | `/jelajahi*` |

Sudah benar: SATU indikator (bukan kapsul per item), navigasi tidak ditunda, posisi
terakhir dipertahankan. Yang kurang: tidak ada blur/transparansi nyata (token solid),
tidak ada label animasi, ikon gambar tangan (bukan set ikon konsisten).

## 4. Temuan visual (dari screenshot baseline — server lokal build `6SNtvpDBI2bzN6KylkOMb`)

Baseline: `docs/audit/before-redesign/` — 14 PNG (10 desktop 1280×900 + 4 mobile
360×800). Catatan metode: headless shell di sandbox TIDAK bisa memuat situs live
(`ERR_TUNNEL_CONNECTION_FAILED` lewat proxy); screenshot diambil dari server lokal
`next start` port 3001 (build produksi yang sama dengan main). Gambar eksternal
(detil/Antara CDN) tidak termuat di headless — diverifikasi via curl gambar
**tetap 200** (detik 32 KB, Antara 65 KB), jadi itu artefak lingkungan, BUKAN
gambar rusak. Di screenshot, gambar tampil sebagai teks alt.

### 4.1 Beranda (desktop + mobile)
- Hero **hanya teks** ("Pahami dunia. Berdasarkan fakta.") + 2 tombol + kotak cari
  kedua. Tidak ada gambar, tidak ada gerakan, tidak ada hierarki visual yang
  membuat berita utama terasa penting. Ini tampilan paling generik di aplikasi.
- **Tiga kotak cari** di situs: header, hero beranda, halaman `/cari` — duplikasi
  yang membingungkan.
- Kartu "Berita Utama": gambar kiri + teks kanan, rapi tapi datar; tidak ada
  reveal, hover depth, atau rasio gambar yang ditegaskan.
- Mobile 360px: header padat (logo + ikon cari + tema + Masuk + Daftar muat,
  tapi nyaris penuh); hero teks besar terbaca baik; BottomNav menutup bagian bawah
  kartu (konten menggulir di bawah dock — perlu padding bawah yang cukup).
- Navigasi desktop: 7 item + 4 dropdown (Kategori, Fakta & Data, Wawasan, Belajar)
  — hanya desktop; mobile mengandalkan BottomNav + `/jelajahi`.

### 4.2 Artikel (`/artikel/[slug]`)
- Struktur bagus: breadcrumb, lencana CEK SILANG, headline serif besar, kotak
  FACT SCORE, meta, kontrol baca (1/3 Menit, Deep Reading, S/M/L, Mode fokus,
  Jelaskan sederhana, Bookmark, Bagikan, Laporkan Kesalahan), TTS "Dengarkan artikel".
- Cacat: byline **"(draf pipeline)"** — jargon internal bocor ke pembaca.
  Kotak FACT SCORE mengulang: "FACT SCORE: Belum dinilai — Belum dinilai —
  belum ada klaim terverifikasi yang bisa dinilai".
- Tidak ada progress baca, tidak ada reveal gambar, tidak ada transisi masuk.

### 4.3 Graf Pengetahuan (`/graf`)
- **Cacat visual terburuk di aplikasi.** Label simpul terpotong di tepi kiri
  ("olisi Tangkap 5 Orang Bu…", "Aprilia Punya Kans Besar …",
  "OTO: Umat Hindu India Be…"). Garis relasi bersilangan semrawut (18 simpul,
  14 sisi). Pil filter menampilkan kategori kosong dengan gaya sama seperti
  yang berisi: Klaim (0), Sumber (0), Peristiwa (0), Cerita (0), Negara (0).
- Penjelasan panjang di atas graf (paragraf) mendominasi sebelum graf terlihat.

### 4.4 Pencarian (`/cari`)
- Bersih tapi **kosong**: hanya kotak cari + kotak empty-state garis putus-putus
  ("Masukkan kata kunci"). Tidak ada topik yang disarankan, pencarian terakhir,
  atau hasil populer di halaman (fitur itu hanya ada di Command Palette).
- Kontras dengan mandat: pengalaman cari ala Raycast belum ada di halaman ini.

### 4.5 Admin (`/admin` sebagai tamu)
- Mengalihkan ke `/masuk` (form login rapi: Email, Kata sandi, tombol Masuk,
  "Daftar gratis"). Perilaku BENAR. Audit visual admin BLOCKED (lihat §0 butir 5).

### 4.6 Lainnya (dari daftar screenshot)
- `/timeline`, `/observatorium`, `/klaim`, `/perpustakaan`, `/glosarium`:
  screenshot diambil dan tersimpan; pemeriksaan detail per halaman menjadi
  pekerjaan Fase 3 (tidak ada cacat fatal yang terlihat dari thumbnail —
  struktur mengikuti pola Swiss yang sama: hero-label + judul serif + konten).
- Footer: gelap solid, 4 kolom (tentang, Kategori, Layanan, Redaksi & Legal),
  konsisten di semua halaman. Baik, tapi tidak ada elemen interaktif.

## 5. Masalah mobile & performa (temuan awal)

- **Mobile:** header 360px hampir penuh; hero teks-only menyisakan ruang kosong
  besar; BottomNav menutup konten bawah (cek padding); dropdown nav tidak ada di
  mobile (hanya BottomNav + Jelajahi) — dapat diterima, tapi `/jelajahi` harus
  memikul semua navigasi sekunder.
- **Performa:** satu `globals.css` 2.583 baris (monolit, sulit dirawat); gambar
  artikel adalah **hotlink eksternal** (CDN detik/Antara) tanpa fallback lokal —
  bila CDN mati, artikel tampil teks alt; tidak ada `next/image` (sengaja?
  perlu dicek di Fase 3 — jangan asumsikan). Tidak ada pengukuran Lighthouse di
  fase ini (butuh browser live; dicatat sebagai pekerjaan Fase 7).
- **Aksesibilitas:** `prefers-reduced-motion` ada (4 blok); aria-label BottomNav
  dan CommandPalette sudah baik. Focus state + kontras perlu diuji ulang
  sesudah redesign (Fase 7).

## 6. Yang sudah baik (jangan dirusak)

- Sistem token Swiss konsisten; kontras muted diklaim ≥4.5:1.
- Command Palette (Ctrl+K) sudah berfungsi — tinggal poles visual + motion.
- BottomNav: satu indikator bergerak, navigasi tidak ditunda — arsitektur benar.
- Guard admin server-side + `robots: noindex` halaman staf.
- PWA/offline + push VAPID sudah jalan; `sw.js` tidak pernah cache rute sensitif.
- FACT SCORE + gerbang terbit + pipeline ingestion/editorial — JANGAN disentuh.
- Sitemap + RSS + podcast.xml ada.
